# 🩺 MediBook – Doctor Appointment Booking System

## About the Project
MediBook is a web application developed using Node.js and Express.js to demonstrate server-side validation in a doctor appointment booking form.

## Features
- Patient appointment booking form
- Server-side validation using Node.js
- Mobile number validation (10 digits)
- Email format validation
- Age validation (1–120 years)
- Doctor selection validation
- Appointment date validation
- Success and error messages
- GET and POST request handling

## Technologies Used
- Node.js
- Express.js
- HTML
- CSS
- JavaScript

## How to Run Locally
1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the server:

   ```bash
   npm start
   ```

5. Open `http://localhost:3000` in your browser.

## Purpose
This project was created for educational purposes to demonstrate server-side validation, routing, HTTP requests, and responses using Node.js and Express.js.

## Note
This is a demonstration project and is not connected to a real hospital or doctor.
